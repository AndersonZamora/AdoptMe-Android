# 🐾 AdoptMe-Android

Aplicación móvil nativa Android para la visualización y gestión de mascotas en adopción. Los usuarios pueden registrarse, iniciar sesión y explorar las mascotas disponibles para adoptar.

---

## 📱 Características principales

- **Autenticación** — registro e inicio de sesión de usuarios con Firebase Authentication
- **Listado de mascotas** — visualización de mascotas disponibles en adopción
- **Base de datos en tiempo real** — información sincronizada con Firebase

---

## 🛠️ Tecnologías utilizadas

| Categoría | Tecnología |
|---|---|
| Lenguaje | Java |
| UI | XML, RecyclerView |
| Autenticación | Firebase Authentication |
| Base de datos | Firebase Realtime Database |
| IDE | Android Studio |
| Control de versiones | Git, GitHub |

---

## 🚀 Instalación

```bash
# Clonar el repositorio
git clone https://github.com/AndersonZamora/AdoptMe-Android.git

# Abrir en Android Studio
# File → Open → seleccionar la carpeta del proyecto

# Ejecutar en dispositivo o emulador
# Run → Run 'app'
```

> ⚠️ Requiere configurar un proyecto Firebase y agregar el archivo `google-services.json` en la carpeta `/app`.

---

## 📋 Requisitos

- Android 6.0 (API 23) o superior
- Conexión a internet
- Cuenta Firebase configurada
